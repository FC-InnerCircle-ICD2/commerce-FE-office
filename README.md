## 🐾 주요 기능
### 대시보드
- **전체 상품 검색 및 조회**: 상품 데이터를 한눈에 확인할 수 있는 대시보드 제공.

### 상품 관리
- **상품 등록**: 새로운 상품을 추가할 수 있습니다.
- **상품 수정**: 기존 상품 정보를 업데이트할 수 있습니다.
- **상품 삭제**: 필요 없는 상품을 제거할 수 있습니다.
- **상품 조회**: 상품 목록 및 상세 정보를 확인할 수 있습니다.

### 주문 관리
- **주문 조회**: 고객의 주문 내역을 확인할 수 있습니다.
- **주문 검색**: 특정 조건으로 주문 데이터를 검색할 수 있습니다.

### 배너 관리
- **배너 등록**: 홈페이지에 표시될 배너를 추가합니다.
- **배너 수정**: 기존 배너를 업데이트합니다.
- **배너 삭제**: 불필요한 배너를 제거합니다.
- **배너 조회**: 등록된 배너 목록과 상세 정보를 확인합니다.

## 🐾 설치 및 실행 방법
```bash
# 저장소 클론
git clone https://github.com/FC-InnerCircle-ICD2/commerce-FE-office.git

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

## 🐾 프로젝트 구조

```
- api/           #백엔드와의 통신을 담당하는 API 관련 함수들이 위치합니다.
- components     #재사용 가능한 UI 컴포넌트들을 모아둔 폴더입니다.
- hooks          #React 커스텀 훅들이 위치하며, 주로 데이터 fetching과 상태 관리 로직을 포함합니다.
- layouts        #애플리케이션의 전체적인 레이아웃 구조를 정의하는 컴포넌트들이 있습니다.
- pages          #각 라우트에 해당하는 페이지 컴포넌트들이 위치합니다.
- utils          #공통으로 사용되는 유틸리티 함수, 상수, 헬퍼 로직 등이 포함됩니다.
```
